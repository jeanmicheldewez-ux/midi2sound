# Preset Template Format

The current demo can export and import sound templates. The exported data wraps the native `ultrasound.js` preset representation in a public JSON envelope.

## Current Demo Export

```json
{
  "format": "midi2sound-template-v1",
  "exportedAt": "2026-06-02T00:00:00.000Z",
  "engine": "ultrasound.js",
  "tracks": []
}
```

The `tracks` array is currently generated by:

```js
UltraSoundEngine.exportTemplate()
```

Internally, this uses the existing `extractTrackParams(track)` logic from `ultrasound.js`.

## Current Track Fields

Native extracted tracks can contain:

- `tone`: synth/player type.
- `sample`: sample name for player tracks.
- `sampleLen`: sample duration.
- `loop`, `start`, `end`, `rate`: player/looper slice data.
- `fx`: ordered effect names.
- `valtone`: generated synth control values.
- `valfx`: generated effect control values.
- `elemType`: generated effect control types.
- `vol`: track volume.

This works for the current demo, but it is still tied to generated NexusUI control order.

## Proposed Stable Format

Future stable templates should name parameters explicitly:

```json
{
  "format": "midi2sound-template-v1",
  "name": "Example Template",
  "tracks": [
    {
      "id": "track-1",
      "name": "Lead",
      "synth": {
        "type": "Synth",
        "oscillator": {
          "type": "sawtooth"
        },
        "envelope": {
          "attack": 0.01,
          "decay": 0.1,
          "sustain": 0.6,
          "release": 0.4
        },
        "settings": {
          "detune": 0
        }
      },
      "volume": -6,
      "effects": [
        {
          "type": "Filter",
          "settings": {
            "frequency": 800,
            "Q": 1,
            "type": "lowpass"
          }
        }
      ],
      "mapping": {
        "midiChannel": 1,
        "noteRange": [0, 127],
        "cc": []
      }
    }
  ]
}
```

## Import Rules

Current demo import accepts:

- a raw native `tracks` array
- an object with a `tracks` array

Invalid data should be rejected by future schema validation.
